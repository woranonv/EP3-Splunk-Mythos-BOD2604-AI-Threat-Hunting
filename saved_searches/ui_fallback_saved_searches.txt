NAME: bod_hunt_intel
DESC: Intel: open CVEs on the host with CISA KEV and Vulnrichment context. Tokens: host
SPL:
| inputlookup asset_vulnerability_data.csv | eval Host=lower(Host) | search Host="$host$" "Vulnerability State"!="Fixed" | eval cve=upper(CVE) | rename "CVSS v3.0 Vector" AS vector | lookup cisa_kev_lookup.csv cveID AS cve OUTPUT product vulnerabilityName cwes knownRansomwareCampaignUse forensicTriage shortDescription notes | lookup cisa_vulnrichment_lookup.csv cve OUTPUT exploitation automatable technical_impact | eval kev=if(isnotnull(vulnerabilityName),"yes","no") | stats first(kev) AS kev first(product) AS product first(vulnerabilityName) AS name first(cwes) AS cwes first(exploitation) AS exploitation first(automatable) AS automatable first(technical_impact) AS impact first(vector) AS vector first(Port) AS port first(knownRansomwareCampaignUse) AS ransomware first(forensicTriage) AS cisa_forensic first(shortDescription) AS description by cve | sort - kev

SPL:
