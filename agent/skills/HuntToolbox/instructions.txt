HUNT TOOLBOX - MITRE ATT&CK aligned, behaviour-based hunting on CIM data models (no baseline needed)

HOW TO USE
- Every template is a saved search in Splunk. Run it with splunk_run_query using EXACTLY the call line shown, replacing the token values. Do NOT write the SPL yourself and do NOT add other commands to the call.
- Token values: host = hostname, ip = internal IP, et = earliest, lt = latest (from the prompt, for example et=-7d@h lt=now), attackers = comma-separated attacker IPs with no spaces (or none), accounts = comma-separated new account names with no spaces (or none).
- Pass every token listed for the template. Never put quotes or spaces inside a token value.
- Always run COV-1 first. Then run the templates that test each step of your hypothesis, in attack order. Skip templates that do not fit and say why.
- Result per template: SUPPORTED (suspicious rows found), REFUTED (the data model has data for the host but 0 rows), NO TELEMETRY (COV-1 shows no data for that data model).
- Times in results are already formatted strings: copy them exactly.

INTEL | VulnIntelProfile step 1 | lookups
| savedsearch bod_hunt_intel host=<HOST>

COV-1 | Coverage (before hunting) | all data models
| savedsearch bod_hunt_cov1 host=<HOST> ip=<IP> et=<EARLIEST> lt=<LATEST>
HOW TO READ COVERAGE:
- Web, Authentication, Network_Traffic, Endpoint.Processes: 0 events = GAP (no telemetry from that source).
- Change: account changes come from the SAME OS auth logs as Authentication. If Authentication has data, Change is COVERED even with 0 events (0 just means no accounts were changed -> PER-2 is REFUTED, not NO TELEMETRY). Change is a GAP only when Authentication is also 0.

=== TA0011 COMMAND AND CONTROL + TA0010 EXFILTRATION ===
C2-1 / EXF-1 | T1571, T1071, T1041 | Network_Traffic - outbound to public addresses flagged by behaviour (unusual port, >=100 MB, or attacker IP).
| savedsearch bod_hunt_c2exf ip=<IP> et=<EARLIEST> lt=<LATEST> attackers=<ATTACKER_IPS or none>
Repeated connections to a public IP on 80/443 alone are normal (updates, CDN, cloud APIs) and are NOT a C2 finding unless the destination is an attacker IP.
